# סקירת בוטומטי מול FlowsBiz

תאריך: 2026-07-27

## מטרה

מסמך זה מסכם את היכולות של מערכת בוטומטי כפי שנבדקו מול מצב FlowsBiz, ומעריך אילו יכולות כדאי לקחת כהשראה למוצר שלנו, כמה מורכב להוסיף אותן, ומה סדר העבודה המומלץ.

## תמונת מצב שלנו

FlowsBiz היא כבר מערכת קמפיינים ל-WhatsApp, ולא רק בוט בסיסי:

- בניית קמפיין לפי טריגר.
- Flow עם שלבים, שאלות, כפתורים/רשימות, המתנה לתשובה, timeouts והמשך לפי בחירה.
- שליחת קבצים/מדיה, vCard, קישור אישי, referral hub ודירוג ממליצים.
- שמירת אנשי קשר ל-Google/iCloud/manual.
- דשבורד לקוח ודשבורד בעלים.
- תמיכה בכמה providers: whatsapp-web.js, Baileys, Twilio ו-Meta Cloud.
- PostgreSQL ללקוחות חדשים/מועברים, outbox עמיד, health ובדיקות concurrency/recovery.
- הפרדת לקוחות דרך Dokploy, עם deployment ידני ומבוקר.
- תוכנית קיימת לשדרוג Campaign Builder למסך פשוט יותר עם שלושה אזורים: פרטי קמפיין, הגדרות ובניית Flow.

הבסיס שלנו חזק בעיקר בצד של קמפיינים, referral, אמינות flow ודוחות קמפיין.

## מה בוטומטי מציעה

בוטומטי מציגה את עצמה כפלטפורמת שיווק ואוטומציה כללית לעסקים בישראל:

- חיבור WhatsApp Web לא רשמי, ולא Cloud API רשמי.
- REST API מלא, OpenAPI ו-Playground.
- Webhooks.
- Flow ויזואלי בסגנון Make.
- קמפיינים וסגמנטים.
- סוכני AI עם BYOK.
- Knowledge bases.
- MCP server.
- Facebook ו-Clicka.
- Anti-block ו-warmup.
- תמחור SaaS עם מכסות: מכשירים, הודעות, אנשי קשר, flows וסוכני AI.
- חשבונית מס ישראלית, מסלולים ותוכנית חינם.

ההבדל המרכזי: בוטומטי היא פלטפורמת אוטומציה כללית. FlowsBiz היא כרגע מערכת קמפיינים ויראליים/שיווקיים ל-WhatsApp עם ניהול לקוחות.

## סדר עבודה מומלץ

1. להשלים את שדרוג Campaign Builder לפי המסמך הקיים, בלי לשנות את מנוע השיחה.
2. להוסיף ספריית תבניות קמפיין: הגרלה, referral, שמירת איש קשר, שאלון, קטלוג/קובץ והצטרפות לקבוצה.
3. להוסיף preflight/simulator לפני פרסום: שלבים חסרים, קבצים כבדים, timeout חסר, כפתורים ארוכים ו-recovery text חסר.
4. להוסיף סגמנטים ותגיות מתוך אירועי קמפיין.
5. לפתוח Webhooks/API בצורה מדורגת.
6. להוסיף AI בסיסי כ-POC מוגבל, ורק אחר כך Knowledge base.

## מסקנה

לא כדאי להעתיק את בוטומטי כמערכת שלמה. הכיוון הנכון הוא לקחת מהם את שכבת המוצר: הקמה מהירה, תבניות, API/Webhooks, סגמנטים ו-AI כאופציה. מבחינת מנוע קמפיינים ואמינות flow, ל-FlowsBiz כבר יש בסיס עמוק. הפער העיקרי הוא אריזה מוצרית: UI פשוט, תבניות, שימוש עצמי, תיעוד API וחוויית SaaS ברורה יותר.
